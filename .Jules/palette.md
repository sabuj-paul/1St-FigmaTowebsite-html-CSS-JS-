## 2024-05-13 - [Mobile Navigation Accessibility]
**Learning:** Large-scale refactoring of navigation components to improve accessibility (e.g., swapping anchors for buttons and implementing focus management) often exceeds the 50-line micro-UX limit for "Palette".
**Action:** Prioritize high-impact, low-line-count changes like ARIA labels on existing elements and global focus indicator enhancements to stay within the persona's boundaries while delivering immediate accessibility wins.
