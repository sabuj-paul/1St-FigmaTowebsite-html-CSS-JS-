## 2024-05-22 - Accessible Mobile Sidebar Navigation
**Learning:** In static sites using CSS transforms for mobile sidebars, content remains focusable by screen readers even when off-screen unless `visibility: hidden` is applied. Furthermore, internal anchor navigation doesn't automatically trigger UI state changes (like closing the menu), requiring explicit event handlers. Programmatic focus management (returning focus to the trigger) needs a slight delay (e.g., 300ms) to ensure it doesn't conflict with the browser's default anchor scrolling behavior.
**Action:** Always pair `transform` with `visibility` for off-screen menus. Implement `onclick="hideSidebar()"` on all navigation links within the sidebar and use `setTimeout` for focus-return calls to ensure a smooth transition and reliable focus state.
