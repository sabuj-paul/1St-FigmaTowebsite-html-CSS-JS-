## 2026-05-10 - Accessible Mobile Sidebar
**Learning:** Using semantic `<button>` elements for navigation triggers and implementing focus management (shifting focus to the close button on open, and back to the toggle on close) is essential for a truly accessible mobile experience. CSS transitions using `transform` and `visibility` provide a smoother UX than `display: none/flex`.
**Action:** Always prefer semantic buttons over links for state toggles and ensure focus is programmatically managed during UI transitions.
