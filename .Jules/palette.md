## 2025-01-24 - Navigation Accessibility & Focus States
**Learning:** Icon-only navigation toggles implemented with non-semantic elements (like `li` with `onclick`) are completely inaccessible to screen readers and keyboard users. Using semantic `<button>` elements with `aria-label` and `aria-expanded` is essential for communicating state and providing an interactive role. Additionally, default focus states are often insufficient for high-contrast luxury themes; explicit `:focus-visible` styling with the primary brand color ensures the UI is both beautiful and navigable.
**Action:** Always replace `onclick` handlers on non-interactive elements with semantic buttons, and ensure icon-only links have descriptive `aria-label` attributes. Add brand-aligned `:focus-visible` styles to all interactive components.
