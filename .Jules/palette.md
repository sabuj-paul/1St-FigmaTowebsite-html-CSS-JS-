## 2025-05-14 - Accessible Mobile Sidebar Patterns
**Learning:** For mobile sidebars, robust accessibility requires a combination of semantic elements (buttons instead of list-item clicks), ARIA state management (aria-expanded/controls), and precise focus management. A 100ms delay in shifting focus to the close button ensures the element is visible and ready to receive focus after the CSS display change. Crucially, when closing the sidebar via an internal navigation link, focus-return to the trigger should be disabled to avoid conflicting with the browser's natural anchor navigation.
**Action:** Always use `<button>` for menu triggers, implement Escape-to-close listeners, and use a `returnFocus` boolean parameter in the close function to distinguish between manual cancellation and navigation-driven closure.
