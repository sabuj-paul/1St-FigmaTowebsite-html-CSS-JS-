## 2025-01-24 - Accessible Animated Sidebars
**Learning:** For mobile sidebars that use `display: none` or `visibility: hidden` when inactive, programmatic focus management must be carefully timed. Shifting focus to a "Close" button immediately after setting `display: flex` might fail if there's a transition; a short `setTimeout` (100ms) ensures the element is interactive. Conversely, returning focus to the trigger button should only happen when the user explicitly cancels/closes the menu, not when they navigate to a new section, to avoid disrupting the browser's default anchor navigation behavior.
**Action:** Use `setTimeout` for programmatic focus shifts in animated UIs and pass a `returnFocus` boolean to the close handler to distinguish between "cancel" and "navigate" actions.
