## 2025-01-24 - Mobile Sidebar Interaction and Accessibility
**Learning:** Mobile sidebars that don't close automatically upon navigation cause user frustration and obscure the target content. Combining `visibility: hidden` and `transform` provides a smoother transition and better accessibility than `display: none`.
**Action:** Always ensure mobile menu items have click handlers to close the menu upon selection, and use CSS transitions for visibility state changes to improve perceived performance and polish.
